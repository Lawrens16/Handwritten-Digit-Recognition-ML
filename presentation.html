Navigate: learn action values

16 states · left/down/right/up · goal reward +1, otherwise 0

target = reward if terminated else reward + .95 * max(Q[next_state])
Q[state, action] += .1 * (target - Q[state, action])

10,000 episodes, up to 100 steps each. Epsilon: 1.0 → floor 0.05; decay 0.999.

Actual transitions update the table. True terminal states do not bootstrap; time-limit truncations do.
